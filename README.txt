================================================================
 作业答案内联标注工具（独立可执行版）
 hw_annotate —— Homework Answer Inline Annotator
================================================================

一、这是什么
------------------------------------------------------------
把「docx 试卷 → 做题 → 答案红色加粗内联标注到每道题 → 导出 PDF」固化成
一个可直接双击 / 命令行运行的独立程序。

标注样式：
  - 选择题：答案字母写在题干末尾，形如 （B）
  - 完形填空：答案字母紧跟每个 ____16____ 空格之后
  - 阅读表达：答案写在题目下方的横线上
  - 全部红色加粗；自动删除文末旧「参考答案」块


二、系统要求
------------------------------------------------------------
  - Windows 10 / 11（64 位）
  - 无需安装 Python / Word / WPS / LibreOffice，完全离线


三、文件夹内容
------------------------------------------------------------
  hw_annotate.exe      主程序（已内置 Python 与 PyMuPDF）
  _internal\          程序运行所需的依赖库（勿删除、勿改名）
  config.yaml         默认配置（颜色/加粗/后缀/PDF 压缩等）
  answers\            示例答案文件（hw1.json、hw2.json）
  samples\            示例试卷（可用于自测）
  checksums.txt       全文件 SHA256 校验清单（用于核对完整性）
  README.txt          本说明


四、快速开始
------------------------------------------------------------
  1) 打开 PowerShell / CMD，进入本文件夹：

         cd /d "本文件夹路径"

  2) 运行（单个文件 + 现成答案）：

         .\hw_annotate.exe run 试卷.docx -a answers\hw1.json

  3) 运行（整个目录批量）：

         .\hw_annotate.exe run 试卷目录 -a answers\hw1.json answers\hw2.json --out 输出目录

  4) 只校验不写盘：

         .\hw_annotate.exe validate 试卷.docx -a answers\hw1.json


五、输入 / 输出
------------------------------------------------------------
  answers.json 结构：

    {
      "file": "国庆假期作业1.docx",
      "choice":    { "1": "B", "2": "C", "36": "D" },
      "cloze":     { "16": "B", "17": "C" },
      "expression": { "56": "Because her best friend's dad was her role model." }
    }

  输出（默认在输入文件所在目录）：
    <名>_含答案.docx     标注后的 Word 文档
    <名>_含答案.pdf      A4、中英混排、红字答案的 PDF
    <名>.before.docx     原文件快照（备份）
    report.json / .md    校验报告（标注数量、未识别题号、异常）


六、配置
------------------------------------------------------------
  通过 --config 指定配置文件覆盖默认值，可调：
    answer_color        答案颜色（默认 FF0000 红）
    bold                是否加粗（默认 true）
    remove_reference_block 是否删除文末旧参考答案块（默认 true）
    output_suffix       输出后缀（默认 _含答案）
    pdf_compress        是否压缩 PDF（默认 true）


七、常见问题
------------------------------------------------------------
  Q: 双击 exe 一闪而过？
  A: 这是命令行工具，请在 PowerShell / CMD 中运行，或在命令后加参数。

  Q: 提示「未找到匹配的 answers.json」？
  A: 请用 -a 指定答案文件路径，或让 answers.json 与试卷同名。

  Q: 试卷被 Word 占用导致写入失败？
  A: 先关闭 Word 中打开的该文档再重试。
